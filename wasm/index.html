Level-set segmentation

PDE-based "snakes" with interactive feedback control. The original Python (NumPy, SciPy, Matplotlib) runs here in your browser as WebAssembly, so there is no server. Source on GitHub · ibipul.github.io

  1. Pick an image and an algorithm. Leave dt at 0.5 unless you want bigger or smaller steps.
  2. Press Run, then draw the starting region on the image: press, drag around the object, release. The contour then evolves live.
  3. With Control + chanvesse or Control + Bhattacharya, you can steer the contour while it runs. Draw a region on the outlined image around an area that should be inside the object. It shows as a dashed yellow outline and is applied at the next checkpoint (every 50 iterations).
  4. Press Stop to end a run, or Run again to start over.
